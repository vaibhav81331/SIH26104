# Roadmap

Ordered by value for the effort.

## Next 3 months — make it real

| Item | Unlocks |
| --- | --- |
| Real ward boundaries for the eight cities | Real ward-level alerts; retire the synthetic layer |
| Daily civil-registration deaths 2015–2025 (CRS/HMIS) | `fit_local()`: a locally fitted distributed-lag exposure–response, replacing the transferred curve |
| Scheduled live runs (05:30 / 17:30 IST) | Operational forecasts |
| Native-speaker review of Odia and Hindi | Public release of advisories |
| TLS, real API keys, the issuing authority's CAP identity | Production posture |

## 6 months — sharper physics and places

| Item | Unlocks |
| --- | --- |
| Satellite land-surface temperature per ward (MODIS/Landsat) | Replace the UHI parameterisation |
| Ensemble NWP (e.g. ECMWF ENS) | True forecast uncertainty in live mode instead of model-derived band widths |
| Real district boundaries | Replace the cell-assignment stand-in |
| Heat-illness ED/HMIS surveillance feed | Validate the surge estimate; a second target for learning |
| Real candidate cooling-centre buildings | Optimiser picks schools and halls, not ward centroids |

## 12 months — scale

| Item | Unlocks |
| --- | --- |
| Integration with the national CAP-based alert dissemination platform | Reach through existing channels |
| Other states | The pipeline is state-agnostic given a grid and a boundary file |
| Occupational module (construction, MGNREGA, agriculture) | Work-rest schedules by WBGT hour |
| Post-season evaluation loop | Did alerts precede observed spikes? Re-tune bands annually |
